# Python Essentials

## Plataforma de laboratorios

Te damos la bienvenida a la **plataforma de laboratorios** del curso **Python Essentials**. Aquí podrás desarrollar habilidades fundamentales de programación en Python mediante prácticas guiadas y ejercicios diseñados para reforzar los conceptos presentados durante el curso.

A lo largo de los laboratorios trabajarás con el entorno de desarrollo, tipos de datos, variables, expresiones, entrada de información, cadenas de caracteres e indexación, entre otros conceptos fundamentales de Python.

## Lista de laboratorios

Cada capítulo contiene diferentes prácticas diseñadas para ofrecerte una experiencia práctica y progresiva. Haz clic en los enlaces para comenzar.

### [Capítulo 1. Introducción y primeros programas en Python](Capitulo_1/README.md)

* **Práctica 1.1. Posicionamiento de lenguajes de programación**

  * **Descripción**: Comparar la popularidad de distintos lenguajes de programación mediante Google Trends y analizar la disponibilidad de recursos técnicos para identificar su posicionamiento actual.
  * ⏱️ **Duración estimada**: 7 min.

* **Práctica 1.2. Hola Mundo con Python Script**

  * **Descripción**: Crear un espacio de trabajo, desarrollar el primer script en Python utilizando Visual Studio Code y ejecutar un programa básico con la función `print()`.
  * ⏱️ **Duración estimada**: 7 min.

---

### [Capítulo 2. Tipos de datos, variables y expresiones](Capitulo_2/README.md)

* **Práctica 2.1. Consola interactiva de Python en Visual Studio Code**

  * **Descripción**: Utilizar la consola interactiva de Python para ejecutar instrucciones, trabajar con variables e identificar errores comunes como `TypeError` y `NameError`.
  * ⏱️ **Duración estimada**: 5 min.

* **Práctica 2.2. Explorando tipos de datos**

  * **Descripción**: Utilizar la función `type()` para identificar y analizar diferentes tipos de datos disponibles en Python.
  * ⏱️ **Duración estimada**: 7 min.

* **Práctica 2.3. Expresiones y asignación de variables**

  * **Descripción**: Trabajar con asignación de variables, intercambio de valores y expresiones aritméticas y de cadenas para comprender el comportamiento de los operadores en Python.
  * ⏱️ **Duración estimada**: 10 min.

* **Práctica 2.4. Tipado dinámico**

  * **Descripción**: Explorar el tipado dinámico de Python y comprobar cómo una misma variable puede almacenar diferentes tipos de datos durante la ejecución de un programa.
  * ⏱️ **Duración estimada**: 10 min.

---

### [Capítulo 3. Entrada de datos y manipulación de cadenas](Capitulo_3/README.md)

* **Práctica 3.1. Expresiones y entrada de datos**

  * **Descripción**: Crear programas interactivos utilizando `input()`, realizar conversiones de tipos y ejecutar operaciones aritméticas con los datos ingresados por el usuario.
  * ⏱️ **Duración estimada**: 8 min.

* **Práctica 3.2. Métodos de las cadenas de caracteres**

  * **Descripción**: Aplicar métodos de cadenas para buscar, transformar, limpiar y manipular texto utilizando las herramientas integradas de Python.
  * ⏱️ **Duración estimada**: 8 min.

* **Práctica 3.3. Indexación de cadenas**

  * **Descripción**: Acceder a caracteres individuales de una cadena mediante índices y comprender el funcionamiento de las posiciones dentro de una secuencia de texto.
  * ⏱️ **Duración estimada**: 8 min.

* **Práctica 3.4. Corte de cadenas (Slicing)**

  * **Descripción**: Utilizar la técnica de `slicing` para extraer partes específicas de una cadena mediante índices de inicio y fin.
  * ⏱️ **Duración estimada**: 8 min.
